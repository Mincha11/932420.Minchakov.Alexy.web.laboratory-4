# 932420.Minchakov.Alexy.web.laboratory-4
Лаборатории для предмета web-технологии
Реализованные функции

Ввод и вывод данных

prompt() — запрос имени пользователя.

alert() — вывод приветствия и итоговой статистики.

console.log() — вывод результатов анализа в консоль браузера.

Работа с массивом

Используется массив из шести чисел, обозначающих время в играх за неделю в часах.

Выполняется подсчёт общего времени, проведённого в играх.

Функции

findMaximum() — поиск максимального времени.

filterPopularGames() — фильтрация игр, на которые потрачено больше 10 часов.

calculateSum() — подсчёт суммы элементов массива.

Условные конструкции и циклы

Подсчёт количества коротких игровых сессий продолжительностью не более 3 часов.

Вычисление доли коротких игровых сессий в процентах.

Проверка общего времени, проведённого в играх.

Дополнительное условие

Если общее время превышает 25 часов, в консоль выводится предупреждение: «Возможно, стоит сбалансировать время между играми и учёбой».
